pixel_planets_rs

pixel_planets_rs is a Rust/Bevy port of the existing Godot-based PixelPlanets project, a demonstration of a set of shaders which procedurally generate planets. This port, as well as porting the system to a different engine, involved porting the shaders from GLSL to WGSL, modernising both the shader code and the application code, and also the introduction of a brand new API that is used to programmatically create planets so that it can be trivially integrated into a new game. This transforms the project from a simple demo to a much more usable library.

PyGnomeSearchClient

A Python package for interacting with Gnome search providers. Gnome search providers are a convenient way of interacting with applications on your system, but traditionally they can only be accessed when using Gnome shell. However, despite this being how they are traditionally accessed, they are still present when Gnome shell is not running, and can be accessed by calling a standardised dbus method. This package makes discovering and interacting with the providers much more simple than using dbus directly. It's available on PyPI.
